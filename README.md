# 绘本长图公众号 Skills

用 AI 做微信公众号竖屏绘本长图：总文案 → 风格 / 分镜 / 留白落字 → 出图。

| Skill | 作用 |
|-------|------|
| [wechat-pictorial-script](./wechat-pictorial-script) | 想法 / 少量文案 → `master-script.md` |
| [wechat-pictorial-longform](./wechat-pictorial-longform) | 总文案 + 参考图 → 风格 / 镜头 / 落字 / 出图 |

```text
想法 → script → master-script.md → longform → panel-XX.png
```

## 安装（Cursor）

```bash
git clone <本仓库 URL>
cp -r wechat-pictorial-script wechat-pictorial-longform ~/.cursor/skills/
```

Windows：复制到 `%USERPROFILE%\.cursor\skills\`。

## 豆包用户

豆包不能自动安装 Skill，请按 [豆包AI操作指南.md](./豆包AI操作指南.md) 把 `SKILL.md` 贴进对话逐步操作。
