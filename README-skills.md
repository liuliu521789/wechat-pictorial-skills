# 绘本长图 Skills（GitHub 调用）

| Skill | 作用 |
|-------|------|
| [`wechat-pictorial-script`](./wechat-pictorial-script) | 想法 / 少量文案 → `master-script.md` 总文案 |
| [`wechat-pictorial-longform`](./wechat-pictorial-longform) | 总文案 + 参考图 → 风格 / 镜头 / 留白落字 / 出图 |

```text
想法 → script → master-script.md → longform → panel-XX.png
```

- **Cursor 用户**：两个文件夹拷进 `~/.cursor/skills/`，对话里直接点名 skill。  
- **豆包用户**：不能自动安装 skill，按 [`豆包AI操作指南.md`](./豆包AI操作指南.md) 把 `SKILL.md` 贴进对话逐步做。
