# wechat-pictorial-script

把想法或少量文案扩成**绘本长图总文案**（`master-script.md`），再交给 `wechat-pictorial-longform` 出镜头与图片。

## Install

```bash
cp -r wechat-pictorial-script ~/.cursor/skills/
cp -r wechat-pictorial-longform ~/.cursor/skills/   # 出图仍要这个
```

或不安装：对话里 `@wechat-pictorial-script/SKILL.md`。

## Example

```text
按 wechat-pictorial-script：
我是社区调解员，想讲一次因装修噪音起的纠纷，最后用「楼上老人怕吵、楼下孩子要睡」把两边谈拢。
先出总文案，我确认后再分镜出图。
```

确认后：

```text
按 master-script.md 调用 wechat-pictorial-longform 分镜并生成图片
```
